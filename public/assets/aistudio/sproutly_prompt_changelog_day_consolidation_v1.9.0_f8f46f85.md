## Контекст (что и почему — в changelog не переносить)

Записи `1.8.4` и `1.8.3` тоже датированы 2026-10-27 — это итерации одного дня, как и поглощенные ранее 1.8.5–1.8.7. Требование: все правки за 27.10 должны жить в ОДНОЙ записи релиза `1.9.0`. Формулировки — по принципу конечного состояния (элементы, переживший несколько итераций за день — капсула обновления, метка «Закрыт» — описываются один раз, как они выглядят СЕЙЧАС, без истории промежуточных версий).

## Логика слияния (для справки, в код не переносить)

- 18 пунктов трех релизов → 14: промежуточные итерации одного элемента свернуты в конечное состояние (капсула: переезд наверх 1.8.4 + компактность 1.8.5 + calm-фон 1.8.6 → один пункт; «Закрыт»: серый 1.8.3 + угол 1.9.0 → один пункт; типографика: размеры 1.8.3 + заголовки 1.8.3 → один пункт; карточки: выравнивание процентов 1.8.4 + иконки 36px 1.8.3 → один пункт).
- Секция `fixes` — только реальные баги, существовавшие ДО сегодняшнего дня (скачок при сохранении, дерганье диалогов, темная тема доходности). Мигание капсулы в fixes не входит — этот баг родился и умер внутри сегодняшних итераций, пользователи его не видели.
- Порядок `improvements` — по доменам: уведомление об обновлении → таблица вкладов → мобильные карточки → бейджи → окна и зона уведомлений.
