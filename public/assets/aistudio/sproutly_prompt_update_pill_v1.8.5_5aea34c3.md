# Sproutly Pro — v1.8.5: компактное уведомление об обновлении (pill → одна строка + кнопка «Обновить»)

Единственный файл для правки: `src/components/ui/ReloadPrompt.tsx` (плюс одна новая запись в `src/data/changelog.ts`). Больше НИКАКИХ файлов не трогать: `pwaUpdate.ts`, `Layout.tsx`, позиционирование мобильной капсулы — без изменений.

## Проблема (контекст, не для changelog)

1. На планшетах/ПК сайдбар `w-68` (272px) с `px-5` (md) / `px-8` (lg+) даёт всего **232px / 208px** контента. Капсула с заголовком + подзаголовком + крестиком требует ~345px → обе строки обрезаются («Доступно обнов…», «Нажмите, чтобы пр…»).
2. На мобильных капсула спокойная, но теряет внимание, и справа от текста — мёртвая зона ~100–140px.
3. Скрытый риск: сейчас кликабельна вся капсула (`role="button"` + `onClick` на контейнере) — случайный тап запускает перезагрузку приложения посреди ввода данных.

## Целевая анатомия (один компонент — две плотности)

- **Мобильные (<md)** — стеклянная капсула в одну строку:
  `[тайл ✦ 32×32 с пульс-точкой] [«Доступно обновление» — одна строка] [кнопка «Обновить»] [✕]`
- **Сайдбар (md+)** — полноразмерная тинтованная кнопка-чип в ритме навигации:
  `[✦ Обновить]` — без заголовка и крестика (заголовок физически не помещается в 208–232px).

---

## Блок 1 — UpdatePill: убрать глобальную кликабельность контейнера

**Было:** корневой `div` капсулы — `role="button"`, `tabIndex={0}`, `onClick`/`onKeyDown` → `triggerPwaUpdate()`, `cursor-pointer`, `title="Доступно обновление: нажмите, чтобы применить"`.

**Стало:** контейнер — пассивный `div` (без `role`, `tabIndex`, обработчиков, `cursor-pointer`). Обновление запускает ТОЛЬКО кнопка «Обновить» из Блока 3. `role="status" aria-live="polite"` остаётся на внешнем `motion.aside` в `MobileUpdatePrompt` — там ничего не менять.

## Блок 2 — текстовая колонка: одна строка вместо двух

**Было:** `div` `flex-col` с двумя `span`:
- заголовок `text-[13px] font-bold` «Доступно обновление»;
- подзаголовок `text-[10px] font-medium` «Нажмите, чтобы применить» / «Обновление…».

**Стало:** один `span`:
```tsx
<span className="min-w-0 flex-1 text-[12px] font-bold text-slate-950 dark:text-white leading-tight truncate">
  {isUpdating ? 'Обновление…' : 'Доступно обновление'}
</span>
```
Подзаголовок удалён полностью. `flex-1` на тексте прижимает кнопки к правому краю — мёртвая зона исчезает.

## Блок 3 — кнопка «Обновить» (главный акцент)

**Было:** справа только ✕.

**Стало:** перед ✕ добавить настоящую `<button>`:
```tsx
<button
  type="button"
  onClick={() => triggerPwaUpdate()}
  disabled={isUpdating}
  aria-label={isUpdating ? 'Обновление приложения…' : 'Применить обновление'}
  className="h-7 px-2.5 rounded-lg bg-primary-500 hover:bg-primary-600 text-white text-[11px] font-bold shadow-md shadow-primary-500/25 active:scale-95 transition-all flex items-center justify-center w-[76px] shrink-0 cursor-pointer disabled:cursor-default outline-none"
>
  {isUpdating ? <RefreshCw className="w-3.5 h-3.5 animate-spin" /> : 'Обновить'}
</button>
```
Фиксированная `w-[76px]` — чтобы при смене «Обновить» → спиннер кнопка не прыгала по ширине.

## Блок 4 — ✕: остаётся только в мобильной капсуле

В `UpdatePill` ✕ остаётся как есть (кнопка теперь мобильная по определению — см. Блок 6). Добавить только: во время `isUpdating` ✕ скрывается (`{!isUpdating && (...)}`), чтобы нельзя было «отложить» идущее обновление.

## Блок 5 — внимание без неона (капсула)

1. **Пульс-точка на тайле** (язык пульс-точки логотипа SPROUTLY•PRO): тайлу иконки добавить `relative` и внутрь —
```tsx
<span className="absolute -top-0.5 -right-0.5 w-2 h-2 bg-primary-500 rounded-full animate-pulse" aria-hidden="true" />
```
2. **Бордер капсулы** — нейтральный заменить на primary-оттенок:
   было `border border-slate-200/60 dark:border-white/[0.08]` → стало `border border-primary-500/25 dark:border-primary-500/20`.
3. **Тень** — к текущей добавить лёгкий primary-ореол: `shadow-[0_16px_40px_rgba(15,23,42,0.12),0_4px_16px_rgba(var(--rgb-primary),0.10)]` (тёмную тему не трогать). Стекло, `backdrop-blur`, радиус, `py-2 pl-2.5 pr-1.5` — без изменений.

## Блок 6 — SidebarUpdatePrompt: кнопка-чип вместо капсулы

**Было:** внутри `overflow-hidden` обёртки рендерится `<UpdatePill />` (то есть та же двухстрочная капсула — источник обрезки).

**Стало:** содержимое заменить на полноразмерную кнопку (анимация появления `height: auto` + `marginTop: 14` в обёртке сохраняется как есть):
```tsx
<button
  type="button"
  onClick={() => triggerPwaUpdate()}
  disabled={isUpdating}
  aria-label={isUpdating ? 'Обновление приложения…' : 'Применить обновление'}
  className="w-full h-10 rounded-xl flex items-center justify-center gap-2 bg-primary-500/10 dark:bg-primary-500/15 border border-primary-500/20 text-primary-600 dark:text-primary-400 text-[12px] font-bold active:scale-[0.98] transition-all cursor-pointer disabled:cursor-default outline-none"
>
  {isUpdating
    ? <RefreshCw className="w-4 h-4 animate-spin" />
    : <Sparkles className="w-4 h-4" />}
  {isUpdating ? 'Обновление…' : 'Обновить'}
</button>
```
Крестика на md+ нет: dismiss всё равно временный — при следующем возврате фокуса в приложение SW-проверка покажет уведомление снова.
