# Sproutly.Pro 🌿

**Sproutly.Pro** — это премиальный сервис финансового менеджмента для отслеживания банковских вкладов, рассчета налоговой нагрузки и планирования доходов. Проект создан с фокусом на Glassmorphism-дизайн, адаптивность, безопасность данных и удобство использования на любых устройствах.

![Sproutly.Pro](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/leaf.svg)

## 🌟 Ключевые возможности

### 🏦 Управление вкладами
*   **Умный реестр**: Хранение и управление банковскими вкладами в едином удобном интерфейсе.
*   **Умный поиск и фильтрация**: Фильтрация по статусу (Активные/Закрытые), поиск по названиям банков. Интеллектуальный SmartActionBar с адаптацией под любые устройства (Mobile, Tablet Portrait/Landscape, Desktop).
*   **Сортировка**: Удобная сортировка по дате, сумме, процентной ставке и итоговому доходу.
*   **Экспорт**: Возможность выгрузки списка вкладов в форматы PDF, PNG (инфографика) и XLSX (Excel) одним кликом с учетом примененных фильтров.
*   **Тепловая карта оборачиваемости (Heatmap)**: Визуальный календарь окончания сроков вкладов по всем месяцам года и дням недели, для планирования денежных потоков и реинвестирования.

### 📊 Аналитика и НДФЛ
*   **Общий дашборд**: Глобальная сводка по капиталу, процентам и налоговой нагрузке по годам.
*   **Калькулятор НДФЛ налога**: Автоматический трекинг процентных доходов по вкладам с учетом ключевой ставки ЦБ РФ и необлагаемой базы.
*   **Плавающий блок аналитики**: Мобильная кнопка или всплывающий виджет, отображающий текущие данные с учетом применения фильтров (пересчет сумм на лету).

### 🔒 Безопасность и Приватность
*   **Локальное хранилище данных**: Все данные хранятся на устройстве пользователя в IndexedDB (Dexie.js), обеспечивая "Privacy First" подход.
*   **Privacy Blur (Режим инкогнито)**: Скрытие всех денежных сумм по нажатию на иконку глаза на главном дашборде.
*   **ПИН-код и Биометрия**: Защита входа в приложение (опционально, включается в настройках).

## 💻 Технический стек

*   **Фреймворк**: React 18, Vite.
*   **Типизация**: TypeScript (полное покрытие типов и интерфейсов).
*   **Стилизация**: Tailwind CSS (кастомизированный Glassmorphism, темная/светлая тема).
*   **Анимации**: Framer Motion (page transitions, shared layouts).
*   **Хранилище**: Dexie.js (IndexedDB).
*   **Иконки**: Lucide React.
*   **Экспорт данных**: jsPDF, html2canvas, SheetJS (XLSX).

## 🚀 Установка и запуск

Проект полностью настроен для локального запуска и готов к публикации на **Vercel** или другой статический хостинг.

### Локальный запуск
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

### Деплой на Vercel
1. Создайте аккаунт на [Vercel](https://vercel.com/).
2. Импортируйте репозиторий проекта из GitHub.
3. Vercel автоматически определит Vite-конфигурацию.
4. Нажмите **Deploy**. Проект поддерживает "spa" роутинг "из коробки" за счет файла `vercel.json` и билдов Vite.

## 🎨 Дизайн система (Glassmorphism + Dark Mode)
Мы придерживаемся строгих гайдлайнов дизайна `Sproutly.Pro`:
*   Округлости карточек (`rounded-2xl`, `rounded-3xl`)
*   Эффект матового стекла (`backdrop-blur-xl`, `bg-white/60`, для темной темы `bg-slate-950/60`).
*   Фирменные цвета: Emerald (для акцентов вкладов) и Primary Slate.
*   Скрытые скроллбары для чистоты интерфейса.

## 📁 Структура проекта
*   `src/components/dashboard` - Главный экран, виджеты сводки.
*   `src/components/deposits` - Списки вкладов, добавление/редактирование, экспорт.
*   `src/components/income` - Налоговый трекер по месяцам, калькуляторы.
*   `src/components/layout` - Боковое меню, шапка, тулбар мобильной версии.
*   `src/components/settings` - Настройки безопасности и налоговой базы.
*   `src/components/ui` - Общие компоненты (модалки, тосты, свитчеры, блюр).
*   `src/config/db.ts` - Настройка IndexedDB.
*   `src/lib/` - Вспомогательные утилиты, расчеты, словари банков.
*   `src/services/` - Сервисы экспорта в PDF/XLSX/Image.
